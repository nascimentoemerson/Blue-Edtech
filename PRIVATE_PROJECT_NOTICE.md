# Projeto removido do repositório público

Conforme solicitado, o frontend do robô foi removido deste repositório (`Blue-Edtech`) para não ficar público.

## Recomendação

Mantenha o projeto em um repositório privado separado, por exemplo:

- `git@github.com:<sua-org>/trading-bot-private.git`

## Boas práticas de privacidade

- Nunca versionar `.env` com chaves da Binance.
- Ativar branch protection e 2FA.
- Restringir colaboradores apenas ao time necessário.
- Usar secrets no CI/CD e rotação periódica de chaves.
