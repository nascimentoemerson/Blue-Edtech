# Trading Bot Frontend

Frontend estático para controle do robô de trade.

## Rodar localmente

Basta abrir o `index.html` no navegador.

Se quiser usar servidor local:

```bash
python -m http.server 5500
```

Depois acesse `http://localhost:5500/trading-bot-frontend/`.

## Observações

- Esse frontend está em modo simulado.
- Para operar de verdade, conecte a uma API backend privada (não pública) com autenticação.
